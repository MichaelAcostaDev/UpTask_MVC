# 📋 UpTask MVC

A task and project management web application built with **PHP using the MVC (Model-View-Controller) architecture**.

The application allows users to create projects, manage tasks, track task status, and organize their work through a simple and structured interface.

## ⭐ Live Demo

🌐 [Live Application](https://uptask-mvc-michaelacostadev.mnz.dom.my.id/)

## ✅ Features

- 🔐 User registration and authentication
- 📁 Project creation and management
- 📝 Task creation and management
- 🔄 Task status tracking
- 👤 User and project ownership
- 🔒 Password hashing
- 📧 Email functionality
- 🗄️ MySQL / MariaDB database integration
- 📱 Responsive frontend
